
## Features

**Basic Arithmetic Operations:** 

- addition (+)
- subtraction (-)
- multiplication (\*)
- division (/)
- modulo (%)

**Functions:**
 
- Clear Entry (CE): Clears everything.
- Backspace (<): Deletes the last digit entered.
- Memory Store (MS): Stores the current result in memory.
- Memory Recall (MR): Recalls the value stored in memory.
- Negate (NEG): Changes the sign of the current number.
- Decimal Point (.): Allows entering decimal numbers.
- ENTER: Perform calculation

**Number System Conversion:**

- Convert between Binary, Octal, Decimal, and Hexadecimal number systems.
- Select the input and output number systems using dropdown menus.
- Displays the conversion result.
  
**About Information:**

- Simple window that shows some info about the application, including the version and creator.
